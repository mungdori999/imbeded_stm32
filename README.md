# 🌶️ STM32 기반 고추건조기 만들기

STM32 임베디드 프로그래밍을 공부하며 **고추건조기의 온도 제어 시스템을 단계적으로 구현하는 학습용 프로젝트**입니다.

강의자료와 예제 코드를 참고해 GPIO 제어부터 센서 데이터 읽기, 화면 표시, 히터 제어까지 직접 구현하며 학습 과정을 기록합니다.

> 현재 개발 중인 프로젝트입니다. 주변장치별 기초 실습을 진행하고 있으며, 최종적으로 온도 측정과 히터 제어 기능을 통합하는 것을 목표로 합니다.

## 프로젝트 목표

사용자가 목표 온도를 설정하면 온도 센서로 현재 온도를 측정하고, 설정값에 따라 히터를 켜고 끄는 고추건조기 제어 시스템을 만듭니다.

- DS18B20 센서를 이용한 온도 측정
- FND와 OLED를 이용한 온도 및 동작 상태 표시
- 버튼을 이용한 목표 온도 설정
- 릴레이를 이용한 히터 ON/OFF 제어
- 시작 스위치와 LED를 이용한 동작 제어 및 상태 확인

## 개발 환경

- **MCU:** STM32F103C8T7
- **개발 도구:** STM32CubeIDE
- **개발 언어:** C
- **라이브러리:** STM32 HAL, CMSIS
- **버전 관리:** Git / GitHub

## 현재 진행 상황

### 작성된 코드

- GPIO 초기화 및 출력 제어
- FND의 데이터·클록·래치 신호 제어
- 숫자와 일부 문자를 위한 7세그먼트 패턴 정의
- 2자리·4자리 숫자 표시 함수
- 앞자리 0 표시 및 소수점이 포함된 온도 표시 함수
- TIM2 초기화 및 인터럽트 시작 코드
- DS18B20 및 1-Wire 라이브러리 추가

### 앞으로 진행할 작업

- DS18B20 온도 측정 기능을 메인 코드에 연결
- 타이머를 이용한 FND 주기적 표시
- 측정한 온도를 FND에 출력
- 버튼 입력과 목표 온도 설정
- 릴레이 및 히터 제어
- OLED를 이용한 설정 온도와 동작 상태 표시
- 각 기능 통합 및 실제 보드 동작 확인

현재 `gpio_project`의 메인 코드는 GPIO, TIM2, FND 초기화까지 작성되어 있습니다. 온도 측정과 표시, 히터 제어를 연결한 전체 동작은 구현 중입니다.

위 진행 상황은 소스 코드 기준이며, 전체 시스템의 하드웨어 동작 검증 완료를 의미하지 않습니다.

## 프로젝트 구성

- **`first/`**  
  GPIO와 FND 숫자 표시 등 초기 실습 프로젝트입니다.

- **`gpio_project/`**  
  FND 제어와 온도 센서 연동을 단계적으로 진행하는 프로젝트입니다.

- **`gpio_project/Core/Src/`**  
  메인 코드, FND 제어 코드, 인터럽트 처리 코드가 있습니다.

- **`gpio_project/Core/Inc/`**  
  메인 헤더와 STM32 설정 관련 헤더가 있습니다.

- **`gpio_project/Core/Lib/`**  
  DS18B20 온도 센서와 1-Wire 통신 라이브러리가 있습니다.

- **`gpio_project/Drivers/`**  
  STM32 HAL 및 CMSIS 드라이버가 있습니다.

- **`gpio_project/gpio_project.ioc`**  
  MCU 핀과 주변장치 설정을 관리하는 파일입니다.

현재 FND 헤더 파일인 `fnd_controller.h`는 `Core/Src/`에 함께 배치되어 있습니다.

## 최종 동작 흐름

1. 시스템과 주변장치를 초기화합니다.
2. 사용자가 목표 온도를 설정합니다.
3. 건조 동작을 시작하면 센서로 현재 온도를 측정합니다.
4. 현재 온도와 목표 온도를 비교해 히터를 제어합니다.
5. FND와 OLED에 온도 및 동작 상태를 표시합니다.
6. 동작을 중지하면 히터를 끕니다.

이 흐름을 구현하면서 온도 변화에 따른 제어 방식과 주변장치 간 연동을 학습합니다.

## 주요 학습 내용

- STM32 프로젝트 생성 및 주변장치 설정
- HAL 함수를 이용한 GPIO 제어
- 비트 연산과 시프트 레지스터 제어
- FND의 자릿수 분리와 순차 표시
- 타이머와 인터럽트 처리
- 1-Wire 통신과 온도 센서 사용
- 헤더 파일의 선언과 소스 파일의 정의 분리
- 기능별 코드 모듈화
- 컴파일·링크 오류 분석과 Git 버전 관리

## 프로젝트 열기

1. 저장소를 내려받습니다.
2. STM32CubeIDE에서 `first` 또는 `gpio_project`를 기존 프로젝트로 가져옵니다.
3. `.ioc` 파일과 실제 보드의 핀 연결을 확인합니다.
4. 프로젝트를 빌드합니다.
5. 보드와 디버거를 연결한 뒤 코드를 다운로드해 실습합니다.

학습에 활용하는 자료는 다음과 같습니다.

## 기록 목적

완성된 결과뿐 아니라 기능을 하나씩 구현하고 오류를 해결하는 과정도 기록합니다. STM32의 기본 동작을 이해하고, 센서 입력부터 화면 출력과 장치 제어까지 연결하는 임베디드 개발 경험을 쌓는 것이 목표입니다.
